Minecraft Java 1.20.1

Something is in the fog.

Four steps and you're in the world. Takes about ten minutes, most of it waiting for downloads.

You need: a Windows PC and Minecraft: Java Edition on your Microsoft account. Bedrock (the Windows Store version) won't work for this.

  1. Download the installer

    One small file. It installs Forge, all the mods and the shader for you.

    Download install-horror-pack.bat

  2. Run it

    Close the Minecraft Launcher, then double-click install-horror-pack.bat in your Downloads folder.

    If a blue "Windows protected your PC" box shows up, click More info → Run anyway. Wait until the window says ALL DONE. It downloads about 45 MB.

  3. Press Play

    Open the Minecraft Launcher, pick Horror 1.20.1 next to the Play button, and hit Play.

    The first launch is slow, a few minutes is normal. Wait for the Minecraft main menu.

  4. Join the world

    Your friend will send you an address that ends in .e4mc.link.

    In Minecraft: Multiplayer → Direct Connection → paste the address → Join Server.

    The address changes every time the world is opened, so ask for a new one each session.

Second pack: WW2 zombies

  1. Download and run the WW2 installer

    Guns, planes, storms, zombie hordes and a ruined city world, with FPS boosters and a light shader. About 32 MB.

    Download install-ww2-zombies.bat

    Close the Minecraft Launcher first, then double-click the file. If a blue "Windows protected your PC" box shows up, click More info → Run anyway. Wait for ALL DONE.

  2. Play

    In the Minecraft Launcher pick WW2 Zombies 1.20.1 and press Play. Join with the .e4mc.link address, same as the horror pack.

    Host only: when creating the world, click World Type until it says Lost Cities to get the ruined city map. Laggy? Press K to turn the shader off.

If something goes wrong

It says I can't join / mods don't match

Run install-horror-pack.bat again, it fixes missing or old mods. Don't add or update mods inside the pack, both players need exactly the same ones.

The game crashes or is very laggy

Turn the shader off: Options → Video Settings → Shader Packs → switch shaders off. You can also press K in game to toggle it.

Connection timed out

The world has to be open on your friend's PC right now. Ask them to re-open it to LAN and send the new address.

Other way: use the Modrinth App
  1. Install the Modrinth App and sign in with your Microsoft account.
  2. Download horror-pack.mrpack and double-click it.
  3. Open Horror Pack in the app and press Play.
Manual install
  1. Install Java 17 if you don't have Java.
  2. Download the Forge 1.20.1 installer (version 47.4.28), run it, and choose Install client.
  3. Download every mod from the list above (the shader zip goes in a shaderpacks folder instead). Pick the file for 1.20.1 and Forge with the version number shown.
  4. Press Win + R, type %appdata%\.minecraft\mods, and put the mod files in that folder (create it if it's missing).
  5. Open the Minecraft Launcher, pick the forge profile, and press Play.
For the host: how to open the world
  1. Open the Minecraft Launcher, pick the Horror 1.20.1 profile, press Play.
  2. Create or open a singleplayer world.
  3. Press Esc → Open to LAN → Start LAN World.
  4. An address ending in .e4mc.link appears in chat. Click it to copy and send it to your friend.
