Minecraft Java 1.20.1

Something is in the fog.

Five steps and you're in the world. Takes about ten minutes, most of it waiting for downloads.

You need: a Windows PC and Minecraft: Java Edition on your Microsoft account. Bedrock (the Windows Store version) won't work for this.

  1. Get the Modrinth App

    It's a free launcher that installs mods for you.

    Download Modrinth App

    Install it, open it, and sign in with the Microsoft account you play Minecraft on.

  2. Download the horror pack

    One small file that tells the app exactly which mods to get, so we match.

    Download horror-pack.mrpack

  3. Add the pack to the app

    Double-click horror-pack.mrpack in your Downloads folder.

    If nothing happens: in the Modrinth App click the + button, choose From file, and pick the file. Then wait until it finishes installing.

  4. Press Play

    Open Horror Pack in the app and hit Play.

    The first launch is slow, a few minutes is normal. Wait for the Minecraft main menu.

  5. Join the world

    Your friend will send you an address that ends in .e4mc.link.

    In Minecraft: Multiplayer → Direct Connection → paste the address → Join Server.

    The address changes every time the world is opened, so ask for a new one each session.

If something goes wrong

It says I can't join / mods don't match

Delete the Horror Pack in the Modrinth App and do steps 2 and 3 again. Don't add or update mods inside the pack, both players need exactly the same ones.

The game crashes or is very laggy

In the Modrinth App open the pack, click the gear icon, go to Java and memory, and set memory to 4096 MB.

Connection timed out

The world has to be open on your friend's PC right now. Ask them to re-open it to LAN and send the new address.

Extra

What's in the pack

Minecraft 1.20.1 with Forge 47.4.28 and these mods:

  • The Man From The Fog 1.4 — he watches, then he hunts
  • The Knocker 1.5.2 — don't answer the door
  • Cave Dweller Evolved 1.7.0 — something lives in the caves
  • Sound Physics Remastered 1.5.1 — echoes and muffled sounds
  • e4mc 6.2.3 — lets us play together without a server
  • GeckoLib 4.8.4 — needed by the monster mods
Manual install without the Modrinth App
  1. Install Java 17 if you don't have Java.
  2. Download the Forge 1.20.1 installer (version 47.4.28), run it, and choose Install client.
  3. Download the six mods from the list above. Pick the file for 1.20.1 and Forge with the version number shown.
  4. Press Win + R, type %appdata%\.minecraft\mods, and put the six files in that folder (create it if it's missing).
  5. Open the Minecraft Launcher, pick the forge profile, and press Play.
For the host: how to open the world
  1. Open the Minecraft Launcher, pick the Horror 1.20.1 profile, press Play.
  2. Create or open a singleplayer world.
  3. Press Esc → Open to LAN → Start LAN World.
  4. An address ending in .e4mc.link appears in chat. Click it to copy and send it to your friend.
